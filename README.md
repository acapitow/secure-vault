# Secure Vault

Gestionnaire de mots de passe chiffré avec authentificateur TOTP intégré, en Kotlin natif.
Projet portfolio en sécurité mobile, aligné sur l'OWASP MASVS (profil L2) et le Mobile Top 10.

> 🚧 En construction : la documentation complète arrive à l'étape 7.

- 100 % hors ligne (aucune permission réseau)
- AES-256-GCM, Argon2id, Android Keystore (StrongBox), BiometricPrompt + CryptoObject
- APK compilé uniquement par GitHub Actions
